Overview:

This project is a simple Python-based tool that allows users to generate SEO-friendly product titles and descriptions, and store them in a CSV file. It also provides functionality to view and search stored products.

The goal of this project is to combine basic Python concepts (classes, file handling) with real-world application (product listing and SEO generation).

Features:

Add product details (name, category, features)

Automatically generate:

SEO Title

Product Description

Store data in a CSV file

View all saved products

Search for a product and display its SEO content

Technologies Used

Python

CSV File Handling
